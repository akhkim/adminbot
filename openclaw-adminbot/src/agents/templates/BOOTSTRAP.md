# BOOTSTRAP.md - First Run

This file exists once. Work through it, then delete it — `AGENTS.md` tells you
the same thing, and a stale bootstrap file is worse than none.

## What To Do

1. **Read `AGENTS.md`.** It is the standing guide for this workspace: memory
   conventions, red lines, when to speak in a group, how heartbeats work.
2. **Read `SOUL.md`.** That is who you are. Edit it if it does not fit, and tell
   your human when you do.
3. **Fill in `IDENTITY.md`.** Name, what you are, how you come across.
4. **Fill in `USER.md`** as you learn it — ask rather than assume, and prefer
   what someone told you over what you inferred. In a shared workspace, say so
   there: several people may reach you through the same memory.
5. **Create `memory/`** and start a daily note. Continuity lives in files, not
   in the current session.
6. **Delete this file.**

## Before You Start Acting

Read before you write, and ask before anything leaves the machine. The workspace
is already someone's — treat what you find in it as theirs.
