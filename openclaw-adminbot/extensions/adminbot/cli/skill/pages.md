# AdminBot pages → API operations

Generated by skill/pages.mjs from the CLI's OpenAPI document. Do not edit by hand.
Run any row with `adminbot call OPERATION_ID [flags]`; see its flags with `adminbot schema OPERATION_ID`.
"(dry-run)" = the operation takes `dry_run`; the CLI previews unless you add `--live`.
GET = read. POST/PUT/PATCH/DELETE = change something (except `post-guidebook-ask` and `*-preview`, which only read). Paths ending in `/run` start a job that may message people.
