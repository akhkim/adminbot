## Before you paste

A bracketed marker at the end of a line is a status that has to be resolved, not part of the
citation. Delete it once it no longer applies.

| Marker | Meaning |
| --- | --- |
| `[under review]` | The survey records this as *Under Review* at that venue. Presented as a plain venue it would claim an acceptance the lab does not have yet. |
| `[in preparation]` | No venue recorded anywhere. Probably too early to show a funder. |
| `[no public URL]` | Nothing citable found in either sheet. No link was invented, and private Overleaf project URLs were not used as citations. |
| `[accepted]` | Accepted, but no public link yet. |

Lines with **no marker are citable as written** — accepted venue and a working public URL.
